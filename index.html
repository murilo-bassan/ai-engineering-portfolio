01 · governance

toolgate

mcp-tool-gateway ↗

Who may call which tool, with which data — and can you prove it? One MCP server in front of every tool domain, where the stdio client, the web panel and backend services all pass through the same executor.

Quem pode chamar qual tool, com quais dados — e dá para provar? Um servidor MCP na frente de todos os domínios, em que cliente stdio, painel web e serviços passam pelo mesmo executor.

  • Tools as data: JSON Schemas served live; an approved tool appears without restart
  • Per-tool RBAC by glob; clients only see what they can call
  • Dynamic HTTP tools with SSRF guards, secret references and four-eyes approval
  • SHA-256 hash-chained audit trail over PII-masked events
  • Tools como dados: JSON Schemas servidos ao vivo; tool aprovada aparece sem reiniciar
  • Permissão por tool via globs; o cliente só vê o que pode chamar
  • Tools HTTP dinâmicas com proteção a SSRF, secrets por referência e aprovação a quatro olhos
  • Trilha de auditoria com cadeia de hashes SHA-256 sobre eventos mascarados

principles

How I build.

Como eu construo.

01

Models propose, code decides

O modelo propõe, o código decide

Evidence checks, scores and permissions are deterministic. Models do what they are good at.

Checagem de evidência, notas e permissões são determinísticas. O modelo faz o que faz bem.

02

Measure, don't eyeball

Medir, não "achar"

Ground truth, ablations, confidence intervals and CI gates — including when the result is unflattering.

Gabarito, ablações, intervalos de confiança e portões no CI — inclusive quando o resultado não favorece.

03

Design for the crash

Projetar para a falha

At-least-once with idempotent effects, ownership checks on every write, graceful degradation.

Pelo menos uma vez com efeitos idempotentes, checagem de dono em toda escrita, degradação segura.

04

One door, one trail

Uma porta, uma trilha

Every call through the same executor; every action in a tamper-evident log.

Toda chamada pelo mesmo executor; toda ação numa trilha à prova de adulteração.

05

Reproducible by default

Reproduzível por padrão

Synthetic data from fixed seeds, offline model stand-ins, zero keys to run anything.

Dados sintéticos com semente fixa, substitutos offline do modelo, nenhuma chave para rodar.

06

Decisions are written down

Decisões ficam escritas

ADRs explain the trade-off, including what was left out of scope and why.

ADRs explicam o trade-off, inclusive o que ficou fora do escopo e por quê.
