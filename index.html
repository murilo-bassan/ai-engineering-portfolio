toolgate

A control panel for the tools an AI assistant can use. You decide who can use each tool, passwords stay encrypted, and every call is logged so you can check later who did what.

Um painel de controle para as ferramentas que um assistente de IA pode usar. Você decide quem usa cada ferramenta, as senhas ficam criptografadas e toda chamada fica registrada para conferir depois quem fez o quê.

  • Chat with the tools in plain language; conversations are saved
  • A new tool only goes live after another person approves it
  • The log notices if anyone edits an old record
  • Works with Claude Desktop and any MCP client
  • Converse com as ferramentas em linguagem natural; as conversas ficam salvas
  • Ferramenta nova só entra no ar depois que outra pessoa aprova
  • O registro percebe se alguém mexer num evento antigo
  • Funciona com o Claude Desktop e qualquer cliente MCP

Python, FastAPI, MCP, SQLite, Docker

runloop

Runs AI agents on long tasks without losing work. If the server goes down halfway, the agent continues where it stopped and nothing is done twice.

Roda agentes de IA em tarefas longas sem perder trabalho. Se o servidor cair no meio, o agente continua de onde parou e nada é feito duas vezes.

  • Asks a person before actions like placing an order
  • Token limit per user, so costs can't run away
  • Shows each step of the agent live
  • Tested by killing a worker mid-run: 24 of 24 tasks finished, no duplicate orders
  • Pede aprovação de uma pessoa antes de ações como fazer um pedido
  • Limite de tokens por usuário, para o custo não sair do controle
  • Mostra cada passo do agente ao vivo
  • Testado derrubando um worker no meio: 24 de 24 tarefas concluídas, nenhum pedido duplicado

Python, PostgreSQL, FastAPI, Docker

processlens

Reads a business process (a BPMN diagram plus its written description) and suggests what could be automated. Each suggestion points to the part of the document that backs it up.

Lê um processo de negócio (o diagrama BPMN e a descrição escrita) e sugere o que dá para automatizar. Cada sugestão aponta o trecho do documento que a justifica.

  • Suggestions with no source in the documents are thrown out
  • Scores come from a fixed checklist, so the same answers always give the same score
  • Exports the report to Word, HTML or JSON
  • Built as a LangGraph pipeline, one step per job
  • Sugestão sem fonte nos documentos é descartada
  • A nota vem de um checklist fixo: mesmas respostas, mesma nota
  • Exporta o relatório em Word, HTML ou JSON
  • Feito como um pipeline LangGraph, uma etapa para cada tarefa

Python, LangGraph, Pydantic, FastAPI

priceintel

Answers "how much did the government pay for this?" by searching purchase records. It skips items that only look similar, turns boxes and packs into unit prices, and drops values typed in wrong.

Responde "quanto o governo pagou por isto?" buscando em registros de compras. Ignora itens só parecidos, converte caixas e pacotes em preço por unidade e descarta valores digitados errado.

  • Searching "computer" no longer returns computer desks
  • Every number in the answer links to the purchases behind it
  • Turn each step off and watch the estimate get worse
  • Worst error went from 968% to 14% on the test set
  • Buscar "computador" não traz mais mesa para computador
  • Cada número da resposta leva às compras de onde saiu
  • Desligue cada etapa e veja a estimativa piorar
  • O pior erro caiu de 968% para 14% no conjunto de teste

Python, Next.js, TypeScript, pgvector

routebench

Compares ways to decide which tool should handle a request, from a simple keyword list to an LLM, and shows which one is worth what it costs.

Compara formas de decidir qual ferramenta deve atender um pedido, de uma lista de palavras-chave até um LLM, e mostra qual vale o que custa.

  • Counts how often each method acts on requests it should refuse
  • Tells you when a difference is just noise
  • Uses the expensive method only when the cheap one isn't sure
  • Generates an HTML report you can open in any browser
  • Conta quantas vezes cada método age num pedido que deveria recusar
  • Avisa quando uma diferença é só ruído
  • Usa o método caro só quando o barato não tem certeza
  • Gera um relatório HTML que abre em qualquer navegador

Python, NumPy, estatística

About these projects

Sobre os projetos

Each one has automated tests, runs with Docker and ships with sample data, so you can try it on your own machine in a few minutes.

Todos têm testes automatizados, rodam com Docker e vêm com dados de exemplo, então dá para testar no seu computador em poucos minutos.

They work with any OpenAI-compatible model (OpenAI, OpenRouter, Ollama and others). All data is made up, so there's nothing private in them.

Funcionam com qualquer modelo compatível com a API da OpenAI (OpenAI, OpenRouter, Ollama e outros). Os dados são todos fictícios, então não há nada privado.
