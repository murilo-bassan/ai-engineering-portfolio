## Projects

| project | what it does |
|---|---|
| [toolgate](https://github.com/murilo-bassan/mcp-tool-gateway) | A control panel for an AI assistant's tools: who can use each one, encrypted passwords and a log of everything. |
| [runloop](https://github.com/murilo-bassan/durable-agent-runtime) | Runs agents on long tasks without losing work. If the server goes down, it picks up where it stopped and nothing is done twice. |
| [processlens](https://github.com/murilo-bassan/process-automation-agents) | Reads a BPMN process and its description and suggests what to automate, pointing to the text behind each suggestion. |
| [priceintel](https://github.com/murilo-bassan/hybrid-rag-price-intel) | Answers how much the government paid for an item by searching purchase records and filtering out wrong items and values. |
| [routebench](https://github.com/murilo-bassan/llm-routing-eval-lab) | Compares ways to pick the right tool for a request and shows when an LLM is worth the cost. |

Each one has tests, runs with Docker and ships with made-up sample data.
They work with any OpenAI-compatible model.
